## 指摘事項

### 1) 仕様/実装の不整合（重要）
1. README では設定管理に PyYAML を明記しているが、実装は JSON 保存。
2. README では音声入力に WASAPI Loopback を要求しているが、実装はダミー音声生成。
3. README では VAD に Silero VAD を明記しているが、実装は簡易エネルギー閾値。

**影響:** 要件トレーサビリティが下がり、利用者が機能完成度を誤認する。

### 2) 設定反映不足（重要）
- `ConfigManager` の `output_formats` を保持しているが、`SessionController.stop()` で固定 `['txt','json','srt']` を使用。

**影響:** GUI/設定値を変更しても出力形式が反映されない。

### 3) 依存関係と起動体験（重要）
- `run_voice2text.bat` は毎回 `pip install -r requirements.txt` を実行する。
- オフライン/社内プロキシ環境では起動時に失敗しやすい。

**影響:** NF-02（オフライン動作）・NF-07（ワンクリック起動）に抵触しやすい。

### 4) 例外処理/可観測性（中）
- `SessionController._run()` 内で例外を拾わないため、スレッド異常終了時の通知が弱い。
- `metrics.errors` 増分や `transcription.error` イベントが未活用。

**影響:** 本番障害時の原因追跡が難しい。

### 5) GUI分担規約とのズレ（中）
- `docs/development_guide.md` では GUI は Claude Code 担当と定義されるが、今回差分で `src/ui/app.py` まで追加。

**影響:** 開発分担境界の運用ルールに齟齬。

## 改善提案（優先順）
1. **要件差分の明文化**: README に「現実装はモック/プロトタイプ」であることを明記。
2. **設定連携修正**: `output_formats` を `SessionController` へ注入し、stop時に設定を使用。
3. **起動改善**: `.bat` で「初回のみ依存インストール」、失敗時メッセージ改善。
4. **観測性改善**: `_run()` に例外処理とエラーイベント発火、`metrics.errors` 反映。
5. **分担整合**: GUIを別PRに切るか、分担ガイドを更新して合意を取る。
